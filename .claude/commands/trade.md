description: Evaluate a trade using this league's actual scoring
---

Evaluate the trade in $ARGUMENTS.

1. Get each player's value in **this league's scoring** — ask me for the ESPN projected
   numbers rather than using the draft board's FP column, which has no bonuses in it.
2. Model the effect on my **starting ten**, remembering a 2-for-1 promotes a bench player
   into the lineup rather than costing a slot.
3. Account for the double-double swing separately — it is not in ESPN's base numbers.
4. Check position eligibility, especially PG.
5. Give Lloyd's read on each player, attributed as opinion.
6. State plainly whether to do it, and what would change the answer.

Flag it if a player in the deal cannot realistically be acquired. Do not commit.
